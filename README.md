# Niecała

A motion-animated walk down **ulica Niecała** in Kalisz, Poland — 230 metres from Plac św. Jana Pawła II to the Town Park.

The street is real. The buildings are real. The photographs are from Wikimedia Commons (credited in the interface). Scroll, drag the progress ticks, or use the arrow keys. Click a façade to read the house.

## What you will find

- The **Noce i Dnie** fountain, on the buried Babinka arm of the Prosna
- **Niecała 2**, the Repphan house, birthplace of explorer Stefan Szolc-Rogoziński
- **Niecała 4 and 6**, Adam Szrajer’s doll factory (now Komoda Residence)
- The **Orthodox church of Saints Peter and Paul** (1928–1930), built from the demolished cathedral
- Albert Nestrypke’s **villa (5)** and the **Szmigielski house (8)**
- The Lutheran **Dom Pod Aniołami** (1913) at number 10
- Wincenty Boretti’s **studio (12)** and **house (14)**
- The **park-keeper’s cottage** and Poland’s oldest public park (1798)

Polish and English throughout.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Next prints (this project is usually started on an uncommon port in preview).

```bash
npm run build
npm start
```

## Research notes

Facts were compiled from the Kalisz municipal site, the Orthodox diocese, the Evangelical-Augsburg parish, Fundacja Nasza Historia, Wikipedia, Calisia.pl, OpenStreetMap, and contemporary reporting on Święto Ulicy Niecałej. Photographs are reused under their Commons licences (CC BY / CC BY-SA / public domain). Where a dedicated façade photograph is not in Commons, the walk uses a documented neighbouring view of the same street rather than an invented picture, and the house dossier says so.
